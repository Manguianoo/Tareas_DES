# Tarea 3

## Tecnologías usadas
- Node.js
- TypeScript

## Funciones implementadas
- `findUserById(id)` - busca un usuario por su id
- `findUsersByName(name)` - busca usuarios cuyo nombre coincida parcial o totalmente
- `findUsersByEmail(email)` - busca usuarios cuyo email coincida parcial o totalmente
- `findUserByRole(role)` - filtra usuarios por rol
- `findUserByStatus(status)` - filtra usuarios por status
