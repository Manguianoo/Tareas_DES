# Tarea 4 - Middleware con Closures

Implementación de un middleware reutilizable en Node.js con Express utilizando closures, capaz de restringir el acceso a diferentes rutas dependiendo del rol del usuario.

## Tecnologías usadas
- Node.js
- TypeScript
- Express

## Instalación

```bash
npm install
```

## Uso

```bash
npm run dev
```
